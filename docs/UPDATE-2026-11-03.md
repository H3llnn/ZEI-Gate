# Menu pengguna, bantuan, dan paket gabungan

## Bot induk

Daftar Pengguna memakai nama tampilan Telegram, tanpa username/ID pada tombol.
Nama disimpan saat pengguna berinteraksi; profil yang belum dikenal dicari lewat Telegram.
Jika profil belum bisa diambil, tombol memakai “Pengguna Telegram”.

Detail Pengguna → Ubah Jenis Izin menampilkan izin aktif dan tiga tombol:
✅/❌ Userbot, Payment, ForceSubs. Tekan untuk mengaktifkan atau mencabut izin layanan itu.
Pesan yang sama langsung diperbarui. Hanya owner bot induk boleh mengubah izin.
Pencabutan menghentikan layanan terkait; pemulihan tetap memerlukan deploy/koneksi ulang.

## Bantuan Userbot

Ketik `.help` menggunakan prefix akun saat ini. Pilih kategori → perintah → fungsi,
cara pakai, dan contoh. Tombol Kembali/Beranda tersedia.
Aktifkan mode inline bot induk melalui `/setinline` di BotFather.
Hanya akun pemilik yang masih aktif dan memiliki izin dapat memakai tombolnya.

## Paket Payment gabungan

Pada bot anak Payment, buka `/setting` → Kelola Akses → Tambah Paket Gabungan.
Isi nama, deskripsi, harga khusus, lalu pilih minimal dua tujuan dari akses satuan.
Tekan Simpan Paket. Foto dapat ditambahkan melalui detail paket → Foto.
Isi paket dapat diubah melalui detail paket → Isi Paket.

Akses satuan tetap dijual. Perbandingan harga dan nilai hemat hanya ditampilkan bila
semua tujuan memiliki harga satuan aktif dan jumlahnya lebih tinggi dari harga paket.
Setelah pembayaran terverifikasi, pembeli mendapat link masuk masing-masing tujuan.
Setiap link hanya sekali pakai, berlaku sampai dipakai, dan dicabut setelah anggota masuk.

Isi pembelian disalin saat pesanan dibuat. Perubahan isi/harga paket setelahnya tidak
mengubah pesanan lama. Link disimpan terenkripsi dan dipakai kembali saat pengiriman diulang.
Jika pembuatan undangan terputus dan hasilnya tidak pasti, bot meminta pemeriksaan owner
agar tidak membuat undangan kedua. Kegagalan pencabutan link tetap dicoba ulang, termasuk
ketika bot anak dihentikan.

Pembaruan skema menambah tabel profil dan kolom paket/pesanan tanpa menghapus data lama.
Hentikan bot dan cadangkan seluruh folder data serta SECRET_KEY sebelum memperbarui.
Uji pembayaran/bergabung nyata tetap perlu dilakukan oleh pemilik sebelum membuka penjualan.
